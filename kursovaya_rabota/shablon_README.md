## Как воспроизвести

Всё выполняется в виртуальной машине с Ubuntu 24.04, скрипты стенда
и приёмки лежат в `~/Downloads`.

```bash
# 1. Развернуть стенд заново
sudo bash ~/Downloads/helpdesk-stand.sh

# 2. Выполнить решение
sudo bash provision.sh

# 3. Запустить приёмку и сохранить вывод
sudo bash ~/Downloads/helpdesk-acceptance.sh | tee acceptance.txt
```
