# Шпаргалка · занятие 4 (15 команд)

| Команда | Назначение | Безопасный пример | Опасный вариант | Чем опасен |
|---|---|---|---|---|
| `mkdir` | создать каталог | `mkdir -pv lab/sub` — видно, что создано | `mkdir /etc/myapp` без прав root | ошибка или создание не там, где нужно |
| `touch` | создать пустой файл / обновить время | `touch notes.txt` | `touch -d '1970-01-01' important.log` | подмена времени изменения, путаница при расследовании |
| `cp` | копировать файлы | `cp -i file.txt backup/` — спросит при замене | `cp -rf /home/user/* /tmp/` | перезапись без вопроса, `-r` затронет лишнее |
| `mv` | перенести или переименовать | `mv -i old.txt new.txt` | `mv * ../other/` из не того каталога | файлы уедут не туда, маска `*` развернётся неожиданно |
| `rm` | удалить файлы | `ls *.bak`, затем `rm -i *.bak` | `rm -rf /` или `rm -rf $VAR/*` при пустом `$VAR` | без корзины, необратимо |
| `rmdir` | удалить пустой каталог | `rmdir empty-dir` | `rmdir dir-with-files` (ожидание, что удалит всё) | не удалит непустой каталог; путаница с `rm -r` |
| `ls` | список файлов | `ls -lah`, `ls -A` для скрытых | `ls -R /` на большой системе | лишняя нагрузка, утечка структуры каталогов |
| `echo` | вывод / проверка масок | `echo *.txt` — показать раскрытие маски | `echo $PATH` в скрипте без кавычек | маска или переменная развернётся не так, как ожидали |
| `find` | поиск по дереву | `find . -name '*.log' -print` | `find . -name '*.tmp' -delete` без проверки | удалит всё подходящее, в том числе нужное |
| `locate` | быстрый поиск по базе | `locate -e os-release` | полагаться на `locate` без `updatedb` | устаревшие пути, «фантомные» удалённые файлы |
| `which` | путь к программе в PATH | `which ls` | `which` для решений безопасности (setuid) | показывает только PATH, не все alias/function |
| `type` | тип имени (builtin/alias/file) | `type cd`, `type ls` | — | — |
| `man` | полная справка | `man ls`, поиск `/size` | `man rm` без чтения DESCRIPTION | удаление «наугад» после неверного ключа |
| `cp -r` | копировать каталог | `cp -ri src/ dst/` | `cp -rf /important /backup` поверх backup | рекурсивная перезапись без `-i` |
| `help` | справка встроенных команд shell | `help cd` | путать с `cd --help` (для builtin нет бинарника) | неверный способ вызова справки для builtin |
