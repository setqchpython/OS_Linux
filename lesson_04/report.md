## Строка ls -l

Команды:

```bash
ls -l, stat -c '%a %U %G %n'
```

![Строка ls -l](screenshots/01-ls-l.png)

Результат: в `~/perm-lab` видны тип `-`/`d`, права, владелец, группа, размер, имя.

Подпишите поля одной строки: тип, три тройки, владелец, группа.

Вывод: первый символ — тип; далее rwx для user/group/other; owner и group.

## Каталог без x и без r

Команды:

```bash
chmod u-x docs; ls docs; cat docs/notes.txt
chmod u-r docs; ls docs
```

![Каталог без x и без r](screenshots/02-dir-rx.png)

Результат: без **x** на каталог — нельзя «зайти» (`ls`/`cat` с ошибкой); без **r** — нельзя прочитать список имён.

Объясните каждую ошибку: что запрещено без x и без r.

Вывод: **x** нужен для обхода каталога; **r** — для listing содержимого.

## Удаление и право w

Команды:

```bash
chmod u-w docs; rm docs/notes.txt
```

![Удаление и право w](screenshots/03-dir-w.png)

Результат: без **w** на каталог `rm` внутри него запрещён.

Почему удаление файла решает каталог, а не файл.

Вывод: удаление = изменение каталога (убрать запись имени), нужна **w** на каталог.

## chmod буквами и числом

Команды:

```bash
chmod -v g-w report.txt; chmod -v 664 report.txt
```

![chmod буквами и числом](screenshots/04-chmod.png)

Результат: `g-w` снимает запись у группы; `664` = rw-rw-r--.

Переведите три своих примера из букв в число и обратно.

Вывод: r=4, w=2, x=1; сумма по тройкам даёт число chmod.

## Владелец и группа

Команды:

```bash
sudo chown boris:boris db.env
```

![Владелец и группа](screenshots/05-chown.png)

Результат: владелец `db.env` сменён на boris.

Почему chown без sudo запрещён, а chgrp на свою группу разрешён.

Вывод: смена владельца — привилегия root; chgrp на группу, где ты состоишь, иногда разрешён.

## umask

Команды:

```bash
umask; (umask 027; touch …; mkdir …)
```

![umask](screenshots/06-umask.png)

Результат: umask вычитается из 666/777; при **027** файл ≈640, каталог ≈750.

Права файла и каталога при маске 0027 — расчёт по тройкам.

Вывод: file 666−027=640; dir 777−027=750.

![Каталоги проекта](screenshots/07-shop-dirs.png)
