## Опыты с graceful.sh

| Опыт | Команда | Код завершения | Пояснение |
|---|---|---|---|
| TERM | `kill -TERM "$pid"` → `wait "$pid"` | **0** | сработал `trap`: temp-файл удалён, нормальный выход |
| KILL | `kill -KILL "$pid"` → `wait "$pid"` | **137** | 128+9 (SIGKILL), обработчик TERM не выполнился |

Пример KILL на ВМ: PID 6592, в shell `[4]+ Killed bash graceful.sh`, `echo $?` после `wait` → 137.

Команда `kill` сама по себе возвращает **0**, если сигнал доставлен; код **137** — это статус убитого процесса после `wait`.

## Цепочка до PID 1

Команда: `pstree -s -p $$`

| Процесс | Пример / роль |
|---|---|
| bash | текущая оболочка (`echo shell pid=5746` на снимке 02-tree) |
| родитель | login / sshd / эмулятор терминала сессии darkle |
| systemd | PID **1**, корень дерева процессов |

Дочерние процессы оболочки: `pstree -p $$` → `bash(5746)---pstree(5760)`.

Дерево procs-lab (manager): `python3(5803)` → worker/hog/stubborn/paused/lab-parent (см. скрин 06-exit).
