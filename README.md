# os-environments · ОП.05 «Операционные системы и среды»

Ваш репозиторий на всю дисциплину. Сюда вы сдаёте практические и домашние
работы: снимки экрана из виртуальной машины Ubuntu, выводы и таблицы. Здесь же
лежат конспекты занятий и файлы, которые раздавались на парах.

## Сделать репозиторий своим

Нажмите **Use this template → Create a new repository**, назовите
`os-<фамилия>` и выберите видимость. Появится собственный репозиторий
с чистой историей. Форк не подходит: он остаётся привязан к исходному.

## Курсовая работа

Техническое задание компании «Пятый склад» на администрирование сервера
Ubuntu, выполняется в паре в отдельном репозитории. Варианты, порядок сдачи,
шаблон README и подготовка к проверке — в [`kursovaya_rabota`](kursovaya_rabota/README.md).
Ссылки сдаются бланком `kursovaya_rabota/kursovaya.md`, коммитом в `main`.

## Снимки экрана

Команды выполняете в своей виртуальной машине, снимок делаете средствами
своей системы: окно виртуальной машины целиком, текст читается. Имена файлов —
те, что указаны в задании. В отчёте снимок вставляется строкой
`![подпись](screenshots/имя.png)`, под ним — вывод своими словами.

## Как сдавать

Все задания сдаются в ветку `main`. Отдельную ветку для задания создавать
не нужно, Pull Request открывать тоже не нужно. Кладёте отчёт и снимки
в папку занятия, коммитите в `main` и отправляете на GitHub.
Срок — до начала следующего занятия.

Всё делается кнопками в VS Code:

| Что нужно | Где посмотреть |
|---|---|
| отобрать файлы и закоммитить | [изменения и коммиты](docs/git/README.md#3-изменения-и-коммиты) |
| отправить коммиты на GitHub | [отправить на GitHub](docs/git/README.md#отправить-на-github) |

## Правила

- Ветку под каждое задание не создавайте: все задания складываются в `main`.
- Снимки и выводы — только из своей машины. Чужие кадры и кадры из лекции
  не принимаются.
- ИИ можно просить поправить формулировки и оформить таблицы в `.md`.
  Команды и их результаты — только из вашего терминала.
